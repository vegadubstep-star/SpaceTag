# SPACE TAG

Windows audio metadata editor by Orbital Trance Records.

Features: manual and automatic filename parsing, MP3/WAV/AIFF metadata, album artwork for MP3 and AIFF, batch editing, original filenames preserved.

Windows installers are built through GitHub Actions. Use Actions > Build Windows Installer to view run artifacts.

**Beta:** Back up your music library before changing tags. Test WAV compatibility on your exact Pioneer/rekordbox setup.
